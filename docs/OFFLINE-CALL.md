# 粤语通话：零付费开发版试用

## 这版能试什么

进入首页的「粤语通话 · 开发版」或「通话体验」，点击绿色电话按钮「开始体验」。

1. 允许麦克风权限，听本地预录的「你好！幾多位？」。
2. 看到「本地收音中」后开口说话，每轮录音 15 秒后自动结束。当前不判断说话停顿。
3. 页面按固定顺序播放下一段预置台词。台词与录音内容无关。
4. 通话中仅保留麦克风和挂断两个主要按钮。字幕默认收起，按需点击「查看字幕」。
5. 挂断后可回放自己的录音。重新开始或退出页面时删除本次录音。

这是**真实本地录音 + 明确标注的固定台词演示**。不是已接入 AI 的语音通话：没有语音识别、自动停顿检测、语音打断、评分或动态回复。每次上限 3 分钟，播完四段台词也会自动结束。

## 如何在微信试用

1. 微信开发者工具导入本目录 `yue-miniprogram`（包含 `project.config.json` 的目录，不是后端目录）。
2. 如修改过代码，在本目录运行 `npm run build:weapp`。
3. 点击开发者工具「编译」，首页进入「通话体验」。也可新建编译模式，启动页面填 `pages/call/index`。
4. 点击「预览」，用绑定该小程序的开发者/体验者微信扫码，在真机测试麦克风及播放。
5. 麦克风被拒绝时，通过微信小程序右上角菜单的设置开启，再重新开始。

若平台提示隐私授权未配置，需要在该小程序的微信后台填写真实的录音用途并完成隐私配置；不要通过绕过检查当作测试成功。

本页四段音频已随包打包，不依赖 `localhost:8080`、登录或服务器。旧页面的接口地址和原有文字 AI 功能没有改动。

## 零付费边界

- 新通话页面没有 AI、ASR、TTS、上传、WebSocket 网络调用；不需要 API Key。
- 不保存到云端、不自动开通服务，不会耗用云端 AI 额度。
- 录音是微信本地临时文件，页面关闭后执行删除；异常退出时由微信临时文件机制管理残留文件。
- 原有网站、后端和原文字聊天功能保持原状，本说明仅覆盖新增通话页。
- 真实语音模型以后需单独配置免费额度和额度耗尽停止机制，本版没有偷偷回退到收费接口。

## 真机验收清单（尚需设备实测）

- [ ] 允许与拒绝录音权限都有清晰反馈。
- [ ] 每轮录音可回放，15 秒后自动结束本轮。
- [ ] 关闭麦克风丢弃正在进行的这一段，开启后重新收音。
- [ ] 挂断后麦克风和声音都停止。
- [ ] 授权弹窗期间挂断，不因后续允许权限而重新开麦。
- [ ] 按返回、切后台、接系统电话均停止当前体验。
- [ ] 重新进入页面后录音正常，不串到旧会话。
- [ ] Android 与 iPhone 扬声器/耳机均测试；本版本不做双工回声消除。

## 本地验证命令

`npm run test:call`：会话取消、录音生命周期及播放行为测试。使用 Node 22+ 的测试运行器，本次使用 Node 25。

`npm run typecheck`：TypeScript 检查。

`npm run build:weapp`：生成微信小程序 `dist`。

开发环境运行测试和构建成功不等于微信真机验收通过。
