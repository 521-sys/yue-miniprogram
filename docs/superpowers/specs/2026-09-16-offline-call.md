# 零付费粤语通话开发版

用户已同意先完成本地通话交互，真实服务仅在免费额度可用时另行接入。本次不申请账号、不购买服务、不调用任何 AI、识别、TTS 网络接口。

## 范围
- 新增独立通话页，首页提供入口；原文字聊天保留。
- 始终展示“离线演示 · 未连接 AI”。对方使用四段已有茶餐厅录音，按固定顺序播放，字幕明确标记预置台词。
- 真机录音、静音、恢复、手动结束本轮、打断示例、挂断、本地录音回放。
- 每轮最多 15 秒，整次体验最多 3 分钟。没有 ASR，因此不显示伪造的用户转写、不自动判断停顿、不做发音评分。
- 使用半双工：示例播放时不收音，打断按钮停止示例并开启收音。零依赖、不增加付费服务。
- 麦克风授权拒绝、录音失败、音频失败均明确提示。退后台自动挂断；卸载页面或新建会话时删除本次录音；挂断后可在页面内回放。
- 取消中的权限弹窗、录音回调、音频回调不得重启已挂断会话。

## 分层
`lib/call/session.ts` 管理会话和取消；`lib/call/media.ts` 封装 Taro 录音和本地播放，设备回调只注册一次并路由到当前录音；`lib/call/demo.ts` 提供打包音频；`pages/call` 展示状态。会话仅依赖媒体接口，不导入既有收费接口。后续真实服务另行设计预算控制及音频传输。

## 验证
Node 内置测试验证取消、权限拒绝、静音恢复、录音回放与过期回调。Taro 构建验证页面及音频打包。真机麦克风、隐私授权和声音效果需微信开发者工具预览验证，不能用自动测试替代。
